# 작업 시작 기본 구성

**도구가 자동으로 읽는 파일이 아니다** — 각 스킬·역할 파일이 `.agents/defaults.md` 경로로 가리켜야 읽힌다.

신규 작업은 설정 질문 없이 아래 구성으로 시작한다. 역할 기본값의 원본은 이 파일 하나이고, 명시한 사용자 변경은 해당 작업에만 적용한다.
이 파일은 **값**만 둔다 — 운영 규칙·리뷰어 구성 변경 기록·리뷰어 사용 불가 시 자동 전환·외부 서치 한도·경쟁 구현의 **규칙**은 [`defaults.rules.md`](defaults.rules.md) 에 있다(paddock 고정).

## 선택 근거

- **2026-09-29 전환 전제**: Opus 5.5·Sonnet 5.5 가 Fable 5.1 보다 지능이 높다는 외부 평을 받아들여
  실측 없이 전환했다. 전제가 틀린 신호(리뷰 라운드 증가, 판정 번복)가 보이면 이 파일부터 되돌린다.
- **코디네이터 = Opus 5.5**: 판단이 가장 비싼 자리라 가장 높은 모델을 둔다. 캐시 읽기 단가도
  불리하지 않다 — Opus 5.5 는 입력 $4 × 캐시 읽기 5% = $0.20/MTok, Fable 5.1 은 $10 × 2.5%
  = $0.25/MTok (2026-09-29 공식 모델 개요 기준). 세션 중간에 모델·effort 를 바꾸면 Fable 5.1 은 10만 토큰 접두사에서 입력 비용이 약 50배로 뛴다. Fable 의 별도 주간 천장에서도 벗어난다.
  effort 는 high — API 기본값이 medium 이라 명시하지 않으면 내려간다.
- **구현 = Opus 5.5 medium** (2026-09-30 사용자 지시, high → medium): 구현 품질이 리뷰 라운드 수를 정한다.
  effort 는 기동 플래그로 **명시**한다(`--effort medium`) — 기본값에 맡기지 않는다. 리뷰 라운드가 늘면 high 로 되돌리는 신호로 본다.
- **advisor 기본 해제**: advisor 는 실행 모델과 등급 차가 있을 때만 발동한다(LIFE-394 실측:
  Fable 코디 0회, Opus 5 워커 23회). Opus 5.5 위의 등급이 없으므로 걸 대상이 없다. 켤 때는 `claude --advisor <모델>`.
- **코드 리뷰 ① = Sonnet 5.5**: 구현자와 다른 모델로 리뷰어의 모델 다양성을 올린다 — 같은
  모델은 같은 결함을 함께 놓친다(LIFE-394 에서 3자가 모두 놓친 높음 결함이 있었다).
- **본체 세션 = Sonnet 5.5**: 시작·마무리는 브랜치·worktree·머지·정리 같은 기계적 절차다.
- 리뷰어는 구현자와 다른 모델을 하나 이상 둔다 — Claude 리뷰어는 구현자(Opus)와 다른 Sonnet 이고 Grok 은 다른 벤더다.
