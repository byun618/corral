## 스캐너는 음성·양성 둘 다 보고, 패턴은 통독으로 모은다

- **Scope:** `app/scripts/**`·작업 폴더 `scripts/` 의 누출·개인 흔적 스캐너, 공개 전 점검
- **Learning:** 빈 패턴은 모든 줄에 맞아 양성 대조가 통과한다 — 빈 패턴을 거절하고 깨끗한 본문 0건(음성)과 심은 표본의 적중(양성)을 둘 다 본다. 패턴은 캡처·로그를 통독해 실제 꼴(URL 인코딩·대시 치환·쪼개진 이름)로 정한다.
- **Evidence:** LIFE-704 빈 패턴이 886건을 잡는데 양성 대조 17/17. LIFE-716 통독이 인코딩·분할 꼴을 찾았다.
- **Disposition:** `.agents/rules/validation.md` 의 양성 대조 줄 — 다시 나면.

## 관측을 원인 문장으로 옮기기 전에 대조군

- **Scope:** 규칙·판정 문서에 실측을 근거로 인용하는 자리
- **Learning:** 실패 관측 한 번을 「X 때문에 Y 였다」로 쓰기 전에 X 만 다른 대조군을 같은 경로로 돌린다. 못 돌리면 「원인은 가르지 못했다」로 적는다. 공유 호스트 수치는 같은 시간대 다른 작업과 겹치는지 먼저 본다. GUI 하네스의 첫 창 회차 실패는 같은 단계를 base 빌드로 돌려 가른다 — 같으면 하네스·기존 동작이고, 회차는 실패로 둔다.
- **Evidence:** LIFE-713 — 모델 부재 탓이라던 멈춤이 다른 모델에서도 났다. LIFE-575 — 배포와 겹친 값을 완화 효과로 보고했다. LIFE-812 — 하네스 결함 5종을 base 대조로 갈랐다.
- **Disposition:** `.agents/rules/validation.md` 양성 대조 줄 옆 — 다시 나면.

## 「제품을 검사한다」로 분류하기 전에 기본 실행에서 도는지 본다

- **Scope:** 시험 분류·정리 일감, task-coordinate §1 분석
- **Learning:** 환경변수로만 켜지는 시험은 기본 실행(`npm test`)에서 skip 이라 보호가 0 이다. 분류 전에 기본 실행에서 실제로 도는지 본다.
- **Evidence:** LIFE-717 — 제품 검사로 분류한 시험 둘이 env 없으면 skip 이었다.
- **Disposition:** 같은 실수 두 번째면 validation.md.

## 새 독자 리허설은 사용자 문맥을 끊고 띄운다

- **Scope:** validation.md 새 독자 리허설, task-coordinate §2 판정 기준
- **Learning:** 리허설 세션은 레포 밖 문서 사본을 cwd 로 띄운다 — 레포 경로에 묶인 자동 메모리가 실리면 「맥락 없음」이 깨진다. 물려받은 API 키 환경변수는 로그인보다 우선하니 리허설 자식에서만 지운다.
- **Evidence:** LIFE-719 — 첫 리허설 둘이 엉뚱한 과금 계정으로 답 없이 끝났다.
- **Disposition:** validation.md 새 독자 리허설 줄 또는 매핑 『세션 기동』 — 다시 나면.

## 화면 판별 문자 집합은 관측이 아니라 소스 분기에서 뽑는다

- **Scope:** `app/backend/herdr-detect.patch` 의 manifest 정규식, 화면 감지 판정 기준
- **Learning:** 판별 문자 집합은 실화면 몇 장이 아니라 대상 프로그램 소스의 모든 그리기 분기(모드·effort·비활성)에서 뽑는다.
- **Evidence:** LIFE-626 — 관측 집합이 Ultra effort·bash 모드를 빠뜨렸다.
- **Disposition:** task-coordinate §2 감지 일감 기준 줄 또는 reviewer.md 감지 리뷰 초점.

## 사용자 설정 디렉터리 복원 관문은 쓰기 주체·디렉터리 항목까지 본다

- **Scope:** 네이티브 관문의 사용자 데이터 백업·복원·대조, task-coordinate §1·§2
- **Learning:** 분석 때 그 디렉터리의 상주 쓰기 주체(데몬·다른 세션)를 먼저 보고, 복원 범위를 소유별(사람 설정 = 바이트 일치, 관문 생성분 = 되돌림, 상주 주체 = 기록만)로 기준에 박는다. 대조는 빈 디렉터리까지 세고 심링크는 따라가지 않는다.
- **Evidence:** LIFE-626 — 바이트 복원 통과선이 상주 데몬 탓에 불가임이 최종 관문에서야 드러났다.
- **Disposition:** validation.md 「원자료 보관」 사용자 데이터 사본 줄 또는 task-coordinate §2.

## 변이 시험은 커밋 뒤에, 사유를 단언하고 판별 장치 전부를 변이한다

- **Scope:** `scripts/*-test.sh`·정리·출고 스크립트 시험, 워커·리뷰어의 변이 양성 대조
- **Learning:** 멈춤 케이스를 「exit≠0·무변경」만으로 판정하면 가드끼리 겹쳐 한 가드를 지워도 통과한다 — 사유 문구를 단언한다. 변이 대상은 `die` 가드만이 아니라 판별 신호·제외 목록·lease 처럼 결과를 가르는 줄 전부이고, 「입력 전부가 그 모양일 때만」 류 가드는 위치 약화 변이(첫 줄만·마지막 줄만)도 넣는다. 단독 변이가 살아남으면 조합 변이로 「겹침」과 「시험 없음」을 가른다. 시험의 기대값은 제품 상수가 아니라 리터럴로 쓴다 — 상수 변이가 엉뚱한 단언에서 죽는다. 변이는 커밋 뒤에만 하거나 사본으로 원복하고(`git checkout --` 는 미커밋 수정도 지운다), mtime 재컴파일 도구는 원복 뒤 `cmp` 와 재컴파일을 본다. 판정 회차 명령은 파이프 없이 종료코드를 받는다.
- **Evidence:** LIFE-724 세 라운드 「지워도 통과」. LIFE-745 변이가 미커밋 수정을 지웠다. LIFE-754 「첫 줄만」 생존, LIFE-708 컴파일 0회, LIFE-755 파이프 탓 `미확정`. LIFE-822 무관한 거절의 exit 1 을 잡은 변이로 셀 뻔했다. LIFE-797 상수 변이가 길이 단언에서 죽었다.
- **Disposition:** task-coordinate §2 변이 양성 대조 정의 줄 — 「exit≠0 만으로 판정 금지」는 다시 발생(LIFE-822), 스킬 수정 일감 후보.

## 관측 스크립트 판정은 대상 범위로 세고, 잘림은 소수점 폭으로 잰다

- **Scope:** 격리·설치본 GUI 관문 스크립트, 01-criteria 관측 항목
- **Learning:** 「페이지의 X 개수 = n」처럼 페이지 전체를 세는 조건은 기존 UI 에 걸린다 — 미리 박는 조건은 대상 요소 안으로 좁히고 전체 수는 기록만 한다. 말줄임·잘림 판정은 정수 폭(`scrollWidth`·`clientWidth`)으로 하지 않는다 — 1px 미만의 넘침도 말줄임을 켠다. 글자 범위의 Range 폭과 상자 폭(`getBoundingClientRect`)을 비교한다. 포인터로 누르는 스크립트는 회차마다 누른 점 아래 요소와 대상 가시성을 남긴다 — 없으면 스크롤 밖을 누른 하네스 실패가 제품 결함처럼 보인다.
- **Evidence:** LIFE-745 — 기존 문구로 수 판정 실패. LIFE-811 — 정수 폭은 같았는데 끝 글자가 `…`. LIFE-823 — 실패 다수가 보이지 않는 좌표, 좌표 없는 1회는 원인 미확정.
- **Disposition:** task-coordinate §2 관문 정의 줄 — 다시 나면.

## 격리 Electron 관측 창은 가림·배경 억제를 끄고 띄운다

- **Scope:** 격리 GUI 관측(CDP 입력) 기동 스크립트
- **Learning:** 다른 창 뒤에 가려진 격리 Electron 창은 렌더러 rAF·타이머가 멈춰 포커스·배치 판정이 거짓 결함으로 나온다. 처음부터 `--disable-backgrounding-occluded-windows --disable-renderer-backgrounding` 로 띄운다.
- **Evidence:** LIFE-825 — 플래그를 붙인 뒤 재현 0.
- **Disposition:** 기동 스크립트가 레포에 들어오면 그 기본값으로 박고 이 항목을 지운다.

## provider 상태를 바꾸는 재현은 데몬 공유를 전제로 정리를 기준에 둔다

- **Scope:** Claude agent view·bg 세션을 만드는 실측, 01-criteria 정리 항목
- **Learning:** pane 을 격리해도 Claude Code 데몬은 사용자 계정 하나라, 재현이 만든 bg 세션이 사용자 목록에 남는다. 기준에 `claude agents --json` 전후 목록 대조와, 자기가 만든 id(cwd·이름 확인)만 지우는 정리 항목을 처음부터 둔다.
- **Evidence:** LIFE-797 — 분석 재현이 bg 세션 둘을 남겼고, 정리 항목을 둔 뒤엔 전후 수가 같았다.
- **Disposition:** task-coordinate §2 격리 실측 기준 줄 — 다시 나면.
